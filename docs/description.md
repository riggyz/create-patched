# Riggyz's Patches
A small Forge mod for that fixes some bugs that affect the survival player experience. This mod will mostly be maintained for my modpacks, but there might be the occasional other bugfix down the line.

## Bugfixes
To keep up with the bug fixes implemented, please refere to the project [README.md](https://github.com/riggyz/riggyz-patches/blob/main/README.md), but here is a shortlist of the important ones added so far.

### Create
- Schematicannon reading no NBT data allowing for item dupes with placards and copycats
- Large trains and contraptions causing massive lag due to slow collision shape calculations
- Updated bound cardboard recipe
- Portable storage interfaces connected intermittently
- CC train station interface causing crashes
- Gantries occasionally stopping or skipping blocks
- Copycats not being emissive
- Xaero's worldmap had some incorrect scaling

### Valkyrien Skies 2
- When creating a ship from world blocks, block entites with NBT would dupe allowing for item dupes.
